# Pocket Blocks 2.0

A phone-first falling-shapes puzzle game for short breaks. This is an original game with its own name, presentation, and extra systems; it is not affiliated with any existing puzzle brand.

## What is new

- Hold slot and ghost landing guide
- Combo scoring, levels, missions, and a chargeable Pulse clear
- Swipe gestures, large touch controls, haptics, keyboard support
- Sound toggle, dark/light theme, pause/resume, local high score
- Accessible labels and reduced-motion support

## Play

Use the touch controls or swipe the board. Keyboard: arrows move, Up rotates, Space drops, C holds, P pauses, N starts over. Fill a row to clear it. Charge Pulse by clearing rows, then press Pulse to remove the lowest occupied row.

## Run

```bash
npm start
```

Open `http://localhost:3000`.
